## 海外VPS价格到底由什么决定

很多人一上来就看 CPU 核数、内存、硬盘，但这些只是表层配置。真正拉开海外 VPS 价格差距的，是三个常被忽略的底层因素。

**机房位置与对华线路质量**是最大变量。同样是洛杉矶机房，走普通 ChinaNet（AS4134）线路的 Basic 套餐可以做到年付 $49.99，而走 CN2 GIA（AS4809）电商线路的同规格套餐，季付就要 $49.99——年付折算下来是 $169.99，直接翻了三倍多。原因很简单：CN2 GIA 的 IP transit 成本可以高达每 Mbps $120，1Gbps 满带宽一个月光线路费就能到六位数美元。便宜和贵之间，差的不是硬盘大小，是线路等级。

**带宽与流量配额**是第二个变量。Basic 套餐普遍给 1Gbps 端口，而电商和 SLA 套餐从 2.5Gbps 起步，顶配可以到 10Gbps。端口速率高不一定意味着你跑得满，但它决定了高峰期能分到多少吞吐。流量方面，低端套餐通常 1TB/月，高端套餐可以到 20TB/月，差距相当悬殊。

**SLA 等级与基础设施冗余**是第三个变量。带 99.99% SLA 的 E-Commerce+SLA 套餐，背后是 Tier III 机房、双路供电、双 NIC 双光纤、24/7 NOC 监控，这些都要算进价格里。如果你只是跑个个人博客，这些冗余大概率用不上；如果你跑的是对华业务，断一次就是真金白银的损失，那这笔钱就值得花。

## CN2 GT 和 CN2 GIA：一字之差，价格和体验差很多

很多刚接触海外 VPS 的人会被 CN2 这个词搞晕。简单说，CN2 是中国电信的下一代承载网，分两个等级：CN2 GT（Global Transit）和 CN2 GIA（Global Internet Access）。

**CN2 GT** 早期确实是优化线路，但官方自己承认，自 2019 年起它的拥堵程度已经和普通 ChinaNet（AS4134）差不多，尽管成本高得多。所以现在看到"CN2"两个字别自动等同于"快"，要看是 GT 还是 GIA。

**CN2 GIA** 才是真正稳定的那条线。搬瓦工在洛杉矶部署了 8 条 10Gbps 的 CN2 GIA/CTGNet 链路，配合与中国移动 CMIN2（AS58807）和中国联通 Premium（AS10099）的直连，是目前对华线路里最靠谱的组合之一。代价就是贵——E-Commerce 套餐比 Basic 套餐贵三倍以上，根源就在这里。

**CTGNet** 是中国电信最新的 IP transit 选项，搬瓦工官方说它在性能和价格上基本等同 CN2 GIA，可以视作同一等级。

选线路的逻辑其实不复杂：如果你的访问者主要在国内，且有稳定性要求，CN2 GIA 是值得多花钱的；如果只是自己用、不面向国内访客、或者纯跑后台任务，Basic 的普通线路完全够用，没必要为用不上的线路溢价买单。

## 购买前需要知道的几件事

**自助管理，没有代管**。搬瓦工是 Self-Managed 服务，价格低的前提是你自己搞定系统配置、安全加固、故障排查。KiwiVM 面板提供开机/关机、重装系统、快照、迁移、rDNS 这些基础操作，但不会有人帮你查 nginx 为什么起不来。如果你完全不懂 Linux，要么先学，要么选别家代管服务。

**机房可以免费迁移**。电商和 SLA 套餐支持在多个机房之间免费切换、不丢数据。这意味着你可以先买洛杉矶，如果发现某个机房对你那条线路表现更好，随时切过去。这个功能比单纯比价格重要得多。

**CN2 GIA 不抗 DDoS**。官方明确说过，CN2 GIA 容量有限，遇到攻击只能 IP nullrouting（直接黑洞）。如果你的业务容易招攻击，CN2 GIA 不是好选择，反而普通 ChinaNet 线路因为容量大、能扛住攻击，在 DDoS 场景下更稳。

**年付比月付划算，但也锁资金**。Basic 20G 年付 $49.99 相当于月付 $4.17，而月付同档通常要 $7.99 左右，年付省接近一半。但 VPS 这行利润薄、商家流动性高，不建议一次性囤太多长周期套餐，尤其是小商家。搬瓦工运营超过十年，相对稳定，但也没必要一上来买三年五年。

## 常见问题

**海外VPS价格为什么比国内便宜这么多？**
核心原因是带宽成本。国内带宽资源紧缺，尤其 BGP 多线带宽，成本可以是海外的数倍。海外机房带宽充裕，普通线路（非 CN2 GIA）价格自然压得很低。一旦你要海外机房回程走 CN2 GIA 优化线路，价格会迅速追上甚至超过国内中高端 VPS。

**$49.99/年那种套餐靠谱吗？**
作为入门或测试用途是靠谱的。这个价位对应 Basic 20G 套餐，1核（资源份额）、1GB 内存、20GB SSD、1TB 流量、1Gbps 端口，跑轻量任务没问题。但线路是普通 ChinaNet 或当地 peering，晚高峰到国内可能丢包明显，别指望它跑对华业务。

**CN2 GIA 套餐值得加钱上吗？**
看你面向谁。访问者主要在国内、且对稳定性有要求——值得。只是自己用、访问者在海外、或者纯后台任务——不值得，Basic 完全够用，省下的钱拿去升内存或硬盘更实在。

**搬瓦工和 Vultr、RackNerd 比怎么选？**
如果你要的是对华线路优化，搬瓦工的 CN2 GIA 体系是这几家里最完整的。Vultr 胜在按小时计费、全球节点多、随时开随时删，适合短期测试和海外业务。RackNerd 以年付低价著称，但线路以普通为主，对华体验一般。三者定位不同，不是简单的贵贱关系。

**能退款吗？**
搬瓦工提供有限退款政策，具体条件以官网 TOS 当前版本为准。一般来说，新购服务在未大量使用流量的情况下有一定退款窗口，但续费通常不退。下单前最好先确认当前退款条款。
